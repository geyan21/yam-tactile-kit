B1 / SENSOR CHOICE & PLACEMENT

Use magnetic sensing in the soft region.
Put thin pressure pads on the nail.

Exactly what to use & where →

B1 per finger: five MLX90393SLW-ABA-011 heads on the fixed side spine, four 3 × 1 mm N48 magnets embedded in the TPU, and two N0 pressure-film pads on the object-facing nail prongs. The magnet/TPU assembly senses soft-region deformation; the film pads cover rigid-tip contacts.

Compliance is a measured design choice.

Compare the original insert with B1 using the same print process. Measure local conformity, nail deflection, creep and return position before choosing a firmer insert.

The spine adds 3.65 mm of global width before screw heads, or 6.05 mm with reserved heads; cables are excluded. Reach and leading-nail geometry remain unchanged.

Files ready for a first bench build

Five checked CAD solids, an editable 8 × 6.4 mm sensor PCB, Gerbers, drill files, wiring, a dedicated Pico program, raw recorder and test instructions.

Magnetic fields are not calibrated force. Add the two existing R1 nail cells for hard-tip contact. The 20 N per finger target still requires physical qualification.

02 / FORCE THROUGH THE MOUNT

Keep the contact surface. Test the complete load path.

L1 assembly guide →

L1 preserves the original nail and TPU geometry. The tradeoff is a larger root: 20 mm more reach, 18.46 mm more width, and about 17.07 mm more back height including reserved screw-head space. A fit witness and off-center cell tests come before the aluminum carrier.

Two stages of force evidence

First calibrate the cell at its center and test displaced loads. Then install the finger, record an explicit unloaded zero, and test eight nail and TPU locations using the same calibration slope.

Selection criteria

Reliable 0.2 N contact detection, useful force feedback through 20 N per finger, intact thin-tip access, repeatable replacement, and acceptable wear across multiple builds.

See the proposed acceptance tests →

Use common contact conditions.

The existing R1/L1 workflow trains at centers, freezes thresholds, then tests leading rims, borders and gaps. Preserve missed contacts, false events and unavailable readings. Magnetic models require measured data and separate validation.
