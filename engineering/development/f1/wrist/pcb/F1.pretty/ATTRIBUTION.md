# Footprint sources

Wrist-board footprints are adapted from the KiCad libraries by the KiCad library contributors, under CC BY-SA 4.0 with the KiCad Libraries Exception:
https://www.kicad.org/libraries/license/
https://creativecommons.org/licenses/by-sa/4.0/

Changes include reference/value fields, mechanical-land numbering, removal of external 3D-model paths and local mask settings. Original source paths and SHA-256 hashes are retained in the board JSON. The exception permits the footprints to be used in PCB designs; the library files retain their stated license.
