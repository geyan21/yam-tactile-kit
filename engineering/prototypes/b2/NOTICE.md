# B2.1 prototype scope

B2 is a new consolidated PCB and removable support for the preserved B1 sensing poses. The original ENPIRE frame and contact outline are attributed to Wenli Xiao / NVIDIA; the exact retrieved source and attribution are documented in engineering/docs/GEOMETRY.md.

This package supplies checked digital CAD, PCB fabrication files, raw acquisition code and assembly material. No physical B2 specimen, calibrated force performance, manufacturing yield or robot qualification is reported. Component solids are dimensional reference envelopes.

The earlier B2 outline/allocation study remains separately in engineering/concepts. Use this package's checked fabrication files for the B2.1 experiment.
