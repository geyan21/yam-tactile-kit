# Source geometry and libraries

The reference frame and TPU come from Open-ENPIRE-Gripper (pgeedh/Open-ENPIRE-Gripper), which credits Wenli Xiao's ENPIRE finger and MakerWorld model 2984746. The pinned source repository declares Apache-2.0; its license is included. The new FB1 carriers, guide mechanism, board and code are kit development. The bench receiver is reused from this kit's C1 design.

KiCad passive footprints retain their library license and attribution under pcb/FB1.pretty. The FMA package is our functional envelope from published manufacturer dimensions; vendor STEP files and complete proprietary data sheets are not redistributed. Gmsh and CalculiX tool versions/provenance are recorded; their executables are not bundled.
