# Scope, provenance, and source rights

The initial design review was prepared on 2026-10-09. This portable software/documentation package was developed on 2026-10-10.

## Implemented

- Research-backed design review and an original conceptual schematic.
- Parameter validation, pad-envelope arithmetic, jaw-opening and stiffness budgets.
- Ideal static two-station moment visualization.
- Synthetic calibration data, fitting, and held-out evaluation.
- An offline interactive website, HTML guide, source archive, and source hashes.
- Reproduction scripts, software tests, optional browser verification, and a GitHub Pages workflow.

## Not implemented or verified

- Dimensioned CAD of the user's exact MakerWorld finger.
- A manufactured force adapter, routed FPC, assembled electronics, or device firmware.
- Actual sensor calibration, gripper fit, force accuracy, fatigue, wear, or production reliability.
- Robot driver/control integration.

The component BOM contains explicit unresolved selections. The measurement template contains `null` fields. Neither should be treated as a complete manufacturing release.

## Source provenance

`docs/DESIGN_REVIEW.md` preserves the original design reasoning and primary source list. Its local integration reference was replaced with `docs/YAM_CONTEXT.md` so the exported repository does not depend on the original workspace.

`web/references.json` supplies the website's primary-source links. It records the original review date for hardware claims. The software build is offline and does not silently refresh those claims.

The user confirmed that the linked MakerWorld finger is the current finger, that a UMI gripper was less suitable for dexterous work, and that reliable contact/grip-force feedback is the first priority. Exact model geometry was not downloaded or measured.

The synthetic CSV is generated by a saved deterministic script. It is not derived from a physical experiment. All screenshots of the website show a conceptual design or explicitly labeled synthetic data.

## Distribution and upstream designs

No upstream sensor source code, firmware, FPC fabrication files, manufacturer CAD, or paper images are included. External references retain their own licensing.

The FlexiTac hardware repository states CC BY-NC 4.0 as checked during the original review. Its article and website can have different licenses. Resolve the appropriate permissions before incorporating upstream hardware into a commercial product.

This package does not assign a new license to the surrounding Flex-π repository or any upstream design. A license for distributing the original kit source should be selected by its owner; no upstream commercial-use permission is implied.

## Publication boundary

The Pages artifact contains the kit's generated website, documentation, BOM/template downloads, and complete source ZIP. It contains no parent-repository source tree, experiment runs, credentials, runtime process logs, or original workspace paths.

When using `--calibration` or `--design`, the supplied build inputs are included in downloads to make that build reproducible. Publish only inputs intended for the site's audience.

The original source archive and Git bundle can be built without a GitHub account. Publishing the requested GitHub repository and Pages site additionally requires an authorized account, repository owner, visibility choice, and a successful remote deployment.
